📌 What is VectorlessRAG?

A RAG pipeline that retrieves relevant context from your docs - zero vector DB, zero embeddings, zero infra headache.
Just chunks → keyword retrieval → LLM answer. That's it.

Why Vectorless?
- ✅ No embedding costs
- ✅ Fully local, no API calls for retrieval
- ✅ Interpretable - you can see why a chunk was retrieved
- ❌ Semantic similarity won't work (e.g. "car" won't match "automobile")
